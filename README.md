# 中継局 見通しマップ(RichField-Viewshed)

牛の首輪(GPS)からの電波を受ける**中継局の設置場所を検討する**ためのWebGISです(GitHub Pagesで動作)。
地図上に中継局を置くと、1m DEMの地形をもとに、**首輪の高さの地点がアンテナから直接見通せる範囲**を色で表示します。
背景地図・DEM・圃場ポリゴンは RichiField2 と同じものを使います。

## できること

- **中継局を置く**:「＋中継局を置く」→ 地図をクリック。アンテナの高さ(地面から)を局ごとに設定。マーカーはドラッグで移動でき、すぐに計算し直します
- **見通し範囲の表示**:緑=1局から見通しあり、青=2局以上から見通しあり、赤=見通し外(計算範囲内)
  - 局ごとにチェックで表示/非表示を切り替え、組み合わせを比べられます
- **断面図**:地図をクリックすると、選んでいる中継局からその地点までの地形の断面を表示
  - アンテナ→首輪の視線、第1フレネルゾーンの60%、地球の丸みを考慮した地形
  - 判定:見通し良好(フレネル60%以上確保)/見通しあり(フレネル一部遮蔽)/見通しなし
  - 距離と自由空間損失(dB)も表示(LoRaなどの回線設計の目安)
- **圃場ごとの見通し率**:RichField圃場2026 の各区画で、見通しのある面積の割合と、種類(採草地・放牧地など)ごとの平均。CSVで書き出し可
- **牛の位置**:RichiField2 と同じスプレッドシート(GPS)から最新位置を読み、見通し内か外かを表示(5分ごとに更新)
- 中継局は自動でブラウザに保存されます。「中継局を書き出す」でGeoJSON(QGISで開けます)に保存し、「読み込む」で再現できます

## 計算の条件(右パネル)

| 項目 | 既定値 | 説明 |
|---|---|---|
| 首輪の高さ | 1.2 m | 受信側(首輪)の地面からの高さ |
| 最大距離 | 3000 m | これより遠い範囲は計算しない |
| 周波数 | 920 MHz | 断面図のフレネルゾーンと損失の計算に使う |
| 解像度 | 2 m | 1 m は精密だが遅い。広い範囲は 5〜10 m で十分 |
| 新しい局の高さ | 5 m | 中継局を置いたときのアンテナ高 |
| 地球の丸み・屈折 | あり | 等価地球半径係数 k=4/3。数km以内なら影響は数十cm程度 |

## 計算方法

- 中継局のアンテナ位置(地盤標高+アンテナ高)から、周囲すべての方向に視線(レイ)を伸ばし、途中の地形で最も高く見える角度より、各セルの首輪の高さ(地盤+1.2m)が上にあれば「見通しあり」とします
- 地形は 距離²/(2kR) だけ下げて、地球の丸みと大気の屈折を考慮(k=4/3、R=6,371km)
- 検証:中継局1か所について、無作為に選んだ4,000セルで、視線上の地形を細かくたどる厳密な判定と比べ、99.9%一致
- 樹木・建物・牛の体は考慮していません(DEMは地表面の高さ)。回折や反射も考慮していないので、「見通し外=通信不可」ではありません。森の縁などでは実測で確かめてください

## DEMと範囲

- 既定のDEMは `data/dem.tif`(興部町 664351 の一部、約2.5×3.4km)。**黄色の点線の外は計算できず**、その外側にある山などによる遮蔽も考慮されません
- 広い範囲を検討するときは、「別のDEMを読み込む」で平面直角座標のGeoTIFFを読み込みます(5mメッシュでも可)。緯度経度のDEMはQGISで平面直角座標に変換してください
- `index.html` の `CONFIG` で、既定のDEM・圃場レイヤ・GPSのURL・計算条件を変えられます

## 公開

1. GitHubで新しいリポジトリ(例 `RichField-Viewshed`、Public)を作成
2. `index.html`・`README.md`・`data`(dem.tif・field_area.gpkg)・`tools` をアップロード
3. 「Settings」→「Pages」→ `main` / `/(root)` →「Save」
4. `https://nabe6318.github.io/RichField-Viewshed/` で開きます

ローカルで確認:`python tools/serve.py` → `http://localhost:8000`
